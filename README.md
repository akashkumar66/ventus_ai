# Ventus AI Funnel - Premium Enterprise Landing Page

This is a world-class, modern SaaS lead-generation funnel website inspired by Ventus AI. It features a visually premium, futuristic, and highly interactive design system.

## Tech Stack
- **React + Vite** (SWC)
- **Tailwind CSS** (Styling)
- **Framer Motion** (Micro-interactions & Animations)
- **GSAP + ScrollTrigger** (Advanced Scroll Animations)
- **Lenis** (Smooth Scrolling)
- **Lucide React** (Premium Icons)

## Design System
- **Colors**: Warm White (#FAFAF7), Secondary (#F4F6F8), Premium Gradients (Sky, Aqua, Mint, Peach).
- **Typography**: General Sans (Headings), Inter (Body).
- **Aesthetic**: Linear + Stripe + Apple + Framer modern AI startup.

## Getting Started

1. **Navigate to the project folder:**
   ```bash
   cd ventus-ai-funnel
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

## Key Features
- **Hero Section**: Massive bold headline with interactive floating UI dashboard.
- **Workflow Demo**: Live system walkthrough with terminal-style logs and status badges.
- **Capabilities**: Premium card grid with tilt and glow effects.
- **Industry Use Cases**: Horizontal parallax scroll for different verticals.
- **Insights Dashboard**: Simulated AI analytics with KPI cards and performance charts.
- **Lead Generation**: Conversion-focused CTA with a modern scheduling form.
